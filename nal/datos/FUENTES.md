# Predictor sources (downloaded 2026-11-15)

- `power_mensual_<region>.csv`: NASA POWER daily point API, community AG, parameters PRECTOTCORR,GWETROOT,T2M_MAX,RH2M, 1 Jan 2001 to 20261031, aggregated to calendar months (rain summed, others averaged). https://power.larc.nasa.gov/api/temporal/daily/point
- `oni.csv`: NOAA CPC Oceanic Nino Index (3-month running mean of ERSSTv5 Nino 3.4 anomalies). https://www.cpc.ncep.noaa.gov/data/indices/oni.ascii.txt
